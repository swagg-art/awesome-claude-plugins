# pandas-ta was dropped deliberately. Two reasons, both measured rather than
# assumed:
#
# 1. The versions that `pandas-ta>=0.3.14b0` now resolves to require Python
#    3.12+, so the install fails outright on 3.11.
# 2. Its RSI uses an unseeded EWM rather than Wilder's SMA-seeded smoothing,
#    which is what MetaTrader's own RSI indicator draws. Over the 100 bars this
#    bot fetches the two agree closely (worst case 0.15 RSI points across 300
#    random series, no threshold disagreements), but during warm-up they differ
#    by 7+ points, and the bot would silently disagree with the chart you are
#    looking at.
#
# RSI is ~15 lines. It now lives in main.py, matches Wilder's published value
# on his canonical series, and has no beta dependency behind it.
